# Links de divulgação (para o painel separar cada canal)

Use **sempre** um link com `utm_source` ao divulgar. O painel (`/painel.html`) mostra, em "De onde vêm", quantas visitas cada canal trouxe, quantas viram o Radar e quantas baixaram.

Modelo: `https://localai4you.vercel.app/?utm_source=CANAL&utm_medium=TIPO&utm_campaign=NOME`

Para uma nova divulgação, troque só `utm_campaign` (ex.: `radar-novembro`). Para um canal que não está na lista, invente um `utm_source` curto, sem espaços.

## Regras de boa conduta

- Leia as regras de autopromoção de cada comunidade antes de postar. Muitas pedem que o post conte algo útil (ex.: "medi estes modelos numa placa X") e não só o link.
- Diga que o projeto é seu. Comunidades de IA local respondem bem a quem é direto sobre isso.
- Um canal por vez, com uns dias de intervalo: assim o painel mostra qual funcionou.

## Como ler o resultado

No painel, em "De onde vêm": se um canal traz muitas visitas mas poucas chegam ao Radar, a promessa do post não bate com o site. Se chegam ao Radar e não baixam, o problema está no passo do download.
