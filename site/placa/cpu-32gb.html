Como esta lista é feita

Só entra o que cabe na memória com compressão de boa qualidade. A ordem prioriza a inteligência estimada do modelo; a velocidade conta até ficar confortável de ler (cerca de 10 tokens por segundo). Tudo aqui é estimado a partir do tamanho real dos arquivos, para Windows. Para medir de verdade no seu computador, o app gratuito faz duelos entre os modelos instalados.

Perguntas comuns

Qual é o melhor modelo de IA para um PC sem placa de vídeo e 32 GB de RAM?

Hoje, o MiniCPM-V-4.7-35B-A3B (Q4_1), que deve gerar cerca de 11 tokens por segundo. Para programar, o mais indicado é o qwen3.6 35B-A3B.

Preciso de internet ou de pagar alguma coisa?

Só de internet para baixar. Depois, o modelo roda no seu computador com o Ollama, um programa gratuito: sem mensalidade e sem enviar suas conversas para ninguém.

Como eu instalo?

Instale o Ollama, abra o terminal e cole o comando que aparece ao lado do modelo. O download começa e, quando terminar, é só conversar.
