Como esta lista é feita

Só entra o que cabe na memória com compressão de boa qualidade. A ordem prioriza a inteligência estimada do modelo; a velocidade conta até ficar confortável de ler (cerca de 10 tokens por segundo). Tudo aqui é estimado a partir do tamanho real dos arquivos. Para medir de verdade no seu computador, o app gratuito faz duelos entre os modelos instalados.

Perguntas comuns

Qual é o melhor modelo de IA para o NVIDIA Jetson AGX Orin com 32 GB?

Hoje, o qwen3.8 27B (Q4_K_M), que deve gerar cerca de 8,7 tokens por segundo. Para programar, o mais indicado é o muse-glimmer 30B.

Só de internet para baixar. Depois, o modelo roda no seu computador com o Ollama, um programa gratuito: sem mensalidade e sem enviar suas conversas para ninguém.

Como eu instalo?
