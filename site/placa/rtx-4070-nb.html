Como esta lista é feita

Só entra o que cabe na memória com compressão de boa qualidade. A ordem prioriza a inteligência estimada do modelo; a velocidade conta até ficar confortável de ler (cerca de 10 tokens por segundo). Tudo aqui é estimado a partir do tamanho real dos arquivos, para Windows, 32 GB de RAM e uma placa. Para medir de verdade no seu computador, o app gratuito faz duelos entre os modelos instalados.

Perguntas comuns

Qual é o melhor modelo de IA para a RTX 4070 Laptop de 8 GB?

Hoje, o MiMo-V2.6-Distill-Qwen-9B (IQ3_M), que deve gerar cerca de 40 tokens por segundo. Para programar, o mais indicado é o ornith-1.5 9B.

Só de internet para baixar. Depois, o modelo roda no seu computador com o Ollama, um programa gratuito: sem mensalidade e sem enviar suas conversas para ninguém.

Como eu instalo?

Instale o Ollama, abra o terminal e cole o comando que aparece ao lado do modelo. O download começa e, quando terminar, é só conversar.
